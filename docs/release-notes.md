Bee 0.1.8 · 播放列表封面与浏览导航

• 播放列表新增封面与封脊视图，根据歌曲所属专辑自动组合最多四张不同封面，以轻微叠层区分专辑与歌单。
• 新增 48 款乐谱回退封面，空列表和缺失封面的专辑固定分配，避免刷新后变化。
• 修复从封面切换到封脊时排列偏右的问题，默认按整排居中。
• 顶部增加前进、后退导航，支持 ⌘[ / ⌘]，移除详情内容区的返回按钮。
• 添加到播放列表改为原生二级菜单，可直接选择具体歌单；右键菜单增加细线小图标。
• 专辑详情播放和添加操作统一为小图标，收紧新建列表弹窗并简化输入框焦点边线。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
