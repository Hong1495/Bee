Bee 0.1.22 · 电台曲目信息与音符音量

• 古典电台主标题显示直播流提供的作品名，副标题组合署名和频道；支持综合频道常见格式拆分，没有信息时显示频道名称，切台和停止后清除旧曲目。
• 「正在播放」与古典电台右上角增加直接可调的音量：细五线谱、小音符滑块和实时百分比，支持拖动、键盘微调及静音。
• 电台下方简化为单一长条播放／停止按钮，唱片页面原有播放控件保持不变。
• 优化深色金色大厅的明暗和边缘融合，延续浅色模式的整体感。

曲目信息由第三方直播源提供，可能缺失或延迟；署名不保证包含完整演出阵容。综合频道使用保守格式识别，有歧义时保留原文。电台可用性受来源及网络影响。
此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
