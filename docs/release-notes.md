Bee 0.1.6 · 自定义播放列表

• 新增 Bee 自定义播放列表：新建、重命名、删除、搜索并批量添加歌曲，以及整张专辑加入列表。
• 支持移除歌曲、拖动排序和右键上移/下移；重复歌曲自动去重。
• Apple Music 与本地音乐的 Bee 列表分别保存。列表播放按完整列表建立队列，编辑或删除列表不影响当前播放队列。Bee 列表仅保存在本机，不回写 Apple Music。
• 系统 Bee 菜单新增「设置…」（⌘,）和「检查更新…」。
• 修正封脊模式默认排列偏右的问题，根据专辑数量居中，并改善切换艺术家和窗口缩放时的定位。
• 增加封脊下方专辑信息与封套的间距，移除专辑详情中多余的「进入播放页」按钮。

适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。此版本使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
