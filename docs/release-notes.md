Bee 0.1.13 · 安静的纯音乐体验

• 纯音乐、歌词查找中、未匹配到歌词及网络失败时保持留白，不再常驻查找或失败提示。
• 识别歌词源返回的“纯音乐，请欣赏”等占位文字，统一作为纯音乐处理；正常歌词不会因包含相关字样而被隐藏。
• 播放页右键菜单新增“重新查找歌词”，支持手动绕过缓存重试；切换曲目后恢复正常缓存读取。
• 更新歌词缓存版本，让此前缓存的纯音乐占位文字重新识别。不根据专辑类型或歌名推断纯音乐。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
