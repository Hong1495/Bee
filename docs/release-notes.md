Bee 0.1.14 · 歌词缓存与匹配修复

• 恢复复用更新前仍有效的歌词缓存，在读取时转换纯音乐占位文字，避免已有歌词因缓存版本变化而被迫重新联网查找。
• 兼容叶倩文、叶蒨文、繁体姓名及 Sally Yeh 的明确别名，修复《烛光》等歌曲因歌手写法差异漏匹配的问题，保留歌曲版本和时长校验。
• 补充正常同步歌词显示、播放时间推进、旧缓存转换和《烛光》真实联网匹配验证。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
