Bee 0.1.21 · 古典电台与金色大厅

• 新增综合古典、宁静钢琴、室内乐、舒缓古典四个 YourClassical 直播频道，无需 Apple Music 订阅。
• 古典电台采用原创金色大厅场景，适配明暗外观；乐队与指挥随播放状态活动，音符缓缓升至屋顶消散。支持系统“减少动态效果”。
• 频道集中在侧栏，独立展开／收起；「正在播放」保留唱片页面，浏览页面不会切换声音。播放唱片时停止电台并恢复歌曲进度。
• 使用熟悉的播放控件与金色配色；支持音量调整、网络超时和有限重试，停止或切台时释放旧连接。
• 电台导航、控件及状态支持简体中文、繁體中文、English、日本語。

电台为第三方在线直播，服务受来源及网络影响；再次播放会回到实时节目。乐队与浮谱为装饰动画，不代表实时曲谱或节拍识别。
此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
