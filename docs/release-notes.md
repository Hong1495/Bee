Bee 0.1.7 · 设置自动保存与界面优化

• 设置修改后自动保存，移除「保存设置」按钮。开关、选项和歌词源调整即时保存；地址在离开输入框或按回车时校验并保存。
• 连续设置修改按顺序写入，保存失败时显示原因并支持重试。
• 移除设置页底部重复的 Logo 与版本信息，版本统一显示在「软件更新」。
• 修复浏览提示音开关被通用按钮样式覆盖的问题，恢复正确的开启颜色、轨道与滑块位置。
• 简化更新提示图标：橙色圆点内仅保留细小的向下箭头。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
