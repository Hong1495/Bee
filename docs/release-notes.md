Bee 0.1.17 · 侧栏材质调整

• 侧栏改用 AppKit 原生 Sidebar 材质，移除整窗 Liquid Glass 与网页模糊的叠加，针对最小化过渡中的材质不一致进行调整。
• 保留侧栏明暗底色及系统“减少透明度”适配，最小化与恢复动画仍由 macOS 管理。
• 保留 0.1.16 的后台播放调度修复。

已通过构建与回归检查；最小化过渡的实际视觉表现仍需运行验证。
此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
