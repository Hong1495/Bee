Bee 0.1.0 · 首个 macOS Apple Silicon 版本

• Apple Music 与本地文件夹音乐库。
• 专辑封面、封脊和黑胶播放界面，支持浅色、深色和系统外观。
• 来源播放队列、播放位置记忆及多源同步歌词。
• 优化封面缓存、搜索、封脊滚动和后台开销。
• 待播放列表时长靠右对齐。
• 自动检查更新、签名校验、下载安装与重启更新。

需要 macOS 12 或更新版本，适用于 Apple Silicon（arm64）。首次安装请将 Bee.app 拖入“应用程序”。此版本尚未使用 Apple Developer ID 签名或公证，macOS 可能阻止首次打开；是否允许打开请按系统提示自行决定。
