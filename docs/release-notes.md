Bee 0.1.19 · 悬停展开侧栏

• 侧栏折叠时，鼠标悬停侧栏按钮可临时展开导航，浮层不挤动内容区域。
• 鼠标离开按钮或侧栏后延时 220 毫秒收起，期间移入侧栏或回到按钮会取消收起。
• 点击导航、点击内容区和按 Esc 不主动关闭浮层；点击侧栏按钮仍可固定展开。
• 浮层复用现有导航与侧栏宽度，适配明暗外观及系统减少动态效果设置。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
