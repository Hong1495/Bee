Bee 0.1.10 · 暗色材质与歌词兼容性

• 优化暗色模式的黑胶沟槽、局部光泽、唱臂金属高光和封套阴影，保持亮色布局与整体风格。
• 非方形封面保持原比例，空余及透明区域使用封面边缘取色；封脊随封面取色并自动选择深浅文字，保留原图已有边框。
• 48 款乐谱回退封面新增暗色纸张配色，切换外观时保持图案一致。
• 修复《上海1943》与《上海一九四三》等数字写法不同造成的歌词漏匹配，增加搜索变体与歌名回退，保留歌手、版本和时长校验。
• 屏蔽封面和普通内容区域的 WebKit 默认右键菜单，保留 Bee 功能菜单及输入框复制粘贴。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
