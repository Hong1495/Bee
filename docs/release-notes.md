Bee 0.1.20 · 四种界面语言

• 设置新增界面语言：简体中文、繁體中文、English、日本語。选项始终使用各自语言的名称，方便识别和切换。
• 切换立即生效并自动保存，保留当前页面与播放状态。
• 导航、播放控件、设置、播放列表操作、排序及右键菜单支持四种语言；Bee 的原生设置／检查更新菜单与文件夹选择标题同步切换。
• 歌曲、艺术家、专辑及自定义播放列表名称保留原文；调整较长翻译在设置中的排布。

系统菜单与权限提示、远程版本说明及底层错误详情仍使用其来源语言。
此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
