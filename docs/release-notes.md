Bee 0.1.16 · 后台播放调度修复

• 关闭主窗口的 WebKit 后台挂起策略，避免窗口隐藏或最小化后播放状态轮询被挂起，导致队列等待回到前台才继续切歌。
• 保留后台暂停唱片动画、歌词刷新等省电处理，不改变界面和播放操作。
• 增加本地音乐和 Apple Music 隐藏状态下的队列回归检查，验证自动切歌及手动暂停后不误恢复。

后台调度设置适用于 macOS 14 及更新版本；macOS 12–13 的后台连续切歌仍待单独验证。真实长时间后台播放仍在持续验证中。
此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
