Bee 0.1.9 · 窗口导航与封面细节

• 前进、后退按钮移至侧栏按钮左侧，展开和收起侧栏时保持位置与间距，独立预留红绿灯右侧的更新圆点位置。
• 系统菜单“检查更新…”保留当前页面，有更新时展开更新面板，无更新或失败时显示简短提示。
• 修复 macOS 27 默认隐藏右键菜单图标的问题，统一图标尺寸，支持系统明暗、选中与禁用状态。
• 播放列表封面模式与专辑统一封面尺寸、留白及播放按钮位置，保留组合封面和轻微叠层效果。
• 封脊文字减小并降低字重，去除静止状态下不必要的变换。
• 播放列表详情增加艺术家、专辑数和总时长，保持简洁的信息层级。

此更新包含此前版本的全部改进，可直接从旧版本升级，无需逐版安装。
适用于 macOS 12 及更新版本的 Apple Silicon（arm64）。使用完整 ad-hoc 签名和独立升级包签名，尚无 Apple Developer ID 签名或 Apple 公证。
