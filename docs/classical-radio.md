# 古典电台

侧栏「播放」分组中，「古典电台」位于「正在播放」下方。电台独立于本地与 Music 资料库，首次使用不需要订阅或连接 Music。

频道在左侧电台子菜单中纵向排列，使用固定乐器图标。播放页不放频道卡片或宣传文案，控制栏复用正在播放页样式；画面四周渐隐融入应用背景。

首批频道：YourClassical Radio、Peaceful Piano、Chamber Music、Relax。连接官方 HTTPS AAC 直播，约 128 kbps、44.1 kHz、立体声。播放由 WebKit 的 HTMLAudioElement 承担，不保存录音、不代理转播。频道在 `src/radio.ts` 集中维护，新增域名须同步更新 Tauri CSP 的 media-src 白名单。

## 交互与显示

- 播放电台先暂停 Bee 的本地／Music 音乐，暂存原队列，禁止队列轮询推进。重新播放专辑会断开电台。
- 停止会释放直播连接。再次播放回到当前直播，无上一首／下一首或拖动进度。
- 15 秒连接／缓冲超时，最多自动重试两次（2 秒、4 秒间隔）。失败后用户可重试或切台。切台、停止和销毁取消旧连接及延迟任务。
- 电台音量在本次会话中保留，切换页面不会把滑杆重置。重启不自动播放。
- 大厅是原创 SVG 界面插画，以维也纳金色大厅的柱廊、管风琴和暖金色为参考，并非场馆照片或直播现场。没有使用生成图片。
- 乐队／指挥动画只随播放状态启停，不声称与实际录音节拍或编制同步。窗口隐藏暂停视觉动画；减少动态效果时禁用动画。
- 支持浅色、深色、跟随系统，以及简体中文、繁体中文、英语、日语。
- 第一版只显示频道信息。ICY 中可能有曲名，但 HTMLAudioElement 不直接暴露这部分元数据；未做网页抓取，也不显示伪造曲名。

## 回归

`npm run check` 包含真实 RadioSession 的假音频／定时器测试及 useMusic 互斥测试：过期事件、缓冲超时、有限重试、停止取消、切台释放、音量、资源回收、本地／Music 暂停、直播时不推进专辑队列和切换来源。

原生验收需确认 AAC 在 WebKit 中可播放，窗口隐藏不停止音频，断网后出现缓冲／错误并可恢复；短时流测试不能代替这些检查。

## 大厅参考

构图调研采用维也纳音乐协会官方大厅页面：https://musikverein.at/en/vermietung/grosser-saal/ 。检查了 Wolf-Dieter Grabner 的乐队演出全景、Leitner 的反向观众席视角，以及官方空场照片，选定观众席后方略高、正对舞台的透视。原创 SVG 抽象保留双侧楼座、透视窗列、三组管风琴、成排水晶吊灯、镀金柱像和分层乐队。参考照片只用于构图研究，没有打包分发或用作运行时背景。

### 大厅铺开与乐队调整

播放场景占满内容区宽度，取消椭圆遮罩及最大宽度限制；只在上下与侧缘短距离淡出，保持舞台全景比例，避免窄窗口裁去侧面乐队。乐队按弧形座次分区、向内朝向指挥，使用侧脸、坐姿、错位身高及共享谱架；小提琴／中提琴、大提琴、低音提琴、长笛、双簧管和圆号使用不同持奏轮廓。指挥为背影视角。动作仍为氛围动画，不与录音节拍同步。

主播放按钮沿用正在播放页面的标准图标与尺寸，仅调整金色配色。播放时指挥上方有少量装饰性五线谱浮起，约 18 秒升至屋顶附近后消散，停止时移除；没有音频转谱或真实曲谱功能。减少动态效果设置会关闭人物及浮谱动画，页面隐藏时暂停装饰动画。

### 导航与播放分离

「正在播放」固定展示保留的唱片会话，「古典电台」展示广播大厅；浏览页面不改变声音。频道列表使用独立展开状态，右侧箭头只展开／收起，不导航、不切台。当前频道重复点击不重连。唱片页面的播放操作显式恢复唱片队列及进度，同时释放电台连接；全局播放快捷键仍可控制活动电台。

### 人物动作与浮谱对比

人物重新绘制为圆润肩线、连续曲线手臂和较小的侧脸，加入服装褶线与谱纸细节。拉弓由固定上臂和绕肘旋转的前臂组成，指挥分别使用肩、腕和腰部锚点，避免整条手臂平移或绕图形中心摆动。各座位使用小幅相位差。浮谱浅色主题为深铜色 `#65402c`，深色为暖金色 `#ffe0a0`，加粗符干并提高可见阶段的不透明度；浮谱独立于大厅压暗滤镜。仍为装饰动画，不分析真实节拍。

控制条现已恢复与「正在播放」一致的标准播放／暂停图标及尺寸，仅保留金色配色；移除乐器按钮、角标与拉弓动画。直播仍采用停止连接、再次点击回到实时直播的语义。
